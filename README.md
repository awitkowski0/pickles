# Pickles

Pittsburgh pickleball court availability at a glance. The RecDesk website makes it painful to see which courts are free when — this pulls from their calendar API and shows all 22 courts across 6 parks on a single timeline view.

Built with Next.js, Bun, Tailwind CSS. Data from https://pittsburgh.recdesk.com.

Running Live here - https://pickles-iota.vercel.app/

![Screenshot of the Site](site-ss.png)

## Run it yourself here

```
bun install
bun dev
```
